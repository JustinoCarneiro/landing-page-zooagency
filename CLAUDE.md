# Zoo Agency — Landing Page

Landing page estática (one-page) da Zoo Agency. O contrato canônico de trabalho
está em `AGENTS.md`; não o duplique aqui.

## Contexto rápido

- **Stack:** HTML5 semântico + CSS3 (design tokens) + JavaScript vanilla. Sem
  framework, sem build, sem dependência de runtime.
- **Estrutura:** `index.html` (raiz, obrigatório), `estilos.css`, `app.js`,
  `fonts.css` + `fonts/`, `imagens/`, `audios/`, `.htaccess`.
- **Arquitetura e decisões:** `ARQUITETURA.md`. **Publicação:** `DEPLOY.md`.
- **Validação:** conferência manual no navegador (desktop + mobile) — carrosséis,
  menu mobile, player de áudio, CTAs.
